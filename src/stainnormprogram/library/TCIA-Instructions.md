# TCIA Instructions

To download images from TCIA, you will need the [IBM Aspera Client (or Connect)](https://www.ibm.com/products/aspera/downloads#Client-deployed+software).

## HANCOCK Dataset

The HANCOCK dataset is at https://www.cancerimagingarchive.net/collection/hancock/. The Download button will take you to the IBM Aspera file browser where you can select the images to download.

Two immunohistochemistry (IHC) slides with diaminobenzidine (DAB) chromogen tissue microarrays (TMAs) can be downloaded at these paths.
* Images / TMA_TumorCenter / CD3 / TumorCenter_CD3_block1.svs
* Images / TMA_TumorCenter / CD3 / TumorCenter_CD163_block14.svs

Two H&E tissue microarrays (TMAs) can be downloaded at these paths.
* Images / TMA_TumorCenter / HE / TumorCenter_HE_block1.svs
* Images / TMA_TumorCenter / HE / TumorCenter_HE_block10.svs
